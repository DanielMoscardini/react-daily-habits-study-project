🧩 Daily Habits — Projeto de Estudo em React
Este repositório contém um aplicativo simples para acompanhamento de hábitos diários, desenvolvido com o objetivo de praticar e consolidar conceitos fundamentais do React.
O projeto é exclusivamente educacional, criado para estudo contínuo e evolução das habilidades em desenvolvimento front‑end.

🎯 Objetivos de aprendizado
Estruturação de componentes reutilizáveis

Gerenciamento de estado com Context API

Edição inline com eventos de teclado (Enter / Esc)

Persistência automática usando LocalStorage

Boas práticas de imutabilidade

Organização de código e arquitetura limpa

Experiência de usuário (UX) moderna

🚀 Funcionalidades
Criar novos hábitos

Incrementar e decrementar contadores

Editar hábitos diretamente na lista

Enter para salvar

Esc para cancelar

Blur para confirmar

Excluir hábitos

Persistência automática no navegador

Interface simples e responsiva

🛠️ Tecnologias
React

Vite

TailwindCSS

JavaScript moderno (ES2023+)

📌 Observação
Este projeto é atualizado conforme novos conceitos são estudados.
O foco é aprendizado contínuo, explorando desde fundamentos até práticas mais avançadas.
